7. Version Notes

v5.0 — DSR-lite

  • Simplified FSRS model with fixed stability initial values
  • No first-exposure grading (all cards start with S=1, D=5)
  • Legacy binary mastery (learned/not learned)
  • Fastest execution, lowest accuracy

v5.1 — DSR-mid (NEW)

  • FSRS-6 core formulas with 12 parameters
  • First-exposure grading: 3-button UI (Forget/Hold/Advance) on first card view
  • Mean reversion target: D0(Good) instead of D0(Easy) — adaptation for 3-button scenario
  • Three dispatchable mastery models: legacy, lite, dsr
  • Unified summary fields including tier_counts, avg_stability, avg_difficulty
  • Balance: ~2.5x better learning than v5.0 at similar cost

v5.2 — FSRS-6 Full

  • Full FSRS-6 with all 5 grades (Again/Hard/Good/Easy/Top)
  • Full parameter set including w3 (S0_Easy), w16 (Easy bonus), w17–w20 (short-term decay)
  • D0(Easy) as mean reversion target — most aggressive interval growth
