بله — ولی نه برای app.kilo.ai/code-reviews

سند رسمی Zen صراحتا می‌گوید: “Have no lock-in by allowing you to use it with any other coding agent.” — یعنی هر کلاینتی که OpenAI/Anthropic-Compatible باشد می‌تواند به https://opencode.ai/zen/v1 بزند. Docker Agent همین کار را می‌کند docs.docker.com/ai/docker-agent/providers/opencode-zen.

کار می‌کند ✅
OpenCode TUI/CLI/IDE — با /connect + opencode.json
هر کلاینت OpenAI-Compatible لوکال (Kilo IDE local /review، Docker Agent، curl) — با baseURL: https://opencode.ai/zen/v1 و کلید Zen
کار نمی‌کند ❌
app.kilo.ai/code-reviews?platform=github
مدل فقط از لیست Kilo Gateway + BYOK انتخاب می‌شود — فیلد Base URL ندارد. kilo.ai/docs/automate/code-reviews/github: “AI Model — Select from available models (default: Claude Sonnet 4.5)”

برای muse-spark-1.2-contributor-free علاوه بر این، باید @ai-sdk/openai روی /v1/responses باشد نه openai-compatible روی /v1/chat/completions — وگرنه ۵۰۰ می‌گیری github.com/anomalyco/opencode/issues/44847. همین هم دلیل دوم ناسازگاری با Kilo Cloud است.

گام ۱ — کلیدت را بردار

همین کی که الان داری (opencode.ai/zen/v1). اگر اکانت جدید خواستی: opencode.ai/zen → Sign in → API Keys.

گام ۲ — OpenCode یا Kilo IDE

فایل ~/.config/opencode/opencode.json را بساز/ادیت کن (روش امن با env):

{ "provider": { "opencode-zen": { "npm": "@ai-sdk/openai", "name": "OpenCode Zen", "options": { "baseURL": "https://opencode.ai/zen/v1", "apiKey": "{env:OPENCODE_API_KEY}" }, "models": { "muse-spark-1.2-contributor-free": {"name":"Muse Spark 1.2 Free"} } } } }
گام ۳ — تست

curl https://opencode.ai/zen/v1/responses -H "Authorization: Bearer $OPENCODE_API_KEY" -d '{"model":"muse-spark-1.2-contributor-free","input":"Say hello"}' باید ۲۰۰ بده. بعد در ترمینال /review branch بزن.
