## نقشه خانه جدید (هر ماژول: یک interface، یک مالک)

| ماژول | interface (آنچه فراخوان و تست باید بدانند) |
|---|---|
| `factory/precard/__init__.py` | فقط `__version__` و `run()` — تنها سطح عمومی |
| `pipeline.py` | ترتیب stageها و assembly؛ transport و index تزریقی می‌گیرد تا hermetic بماند |
| `judge.py` | مرحله sense_judge: ساخت prompt، اعتبارسنج multi-pick (۱ تا ۴، متمایز)، وتوی stub. مالک حقیقت picks همین است |
| `topics.py` | مرحله‌های topic_vectors و topic_label: وکتور، برچسب، نگهبان، متن tie-break. تنها مالک موجودی برچسب (کپی فریز ۱۶تایی زنده با سربرگ provenance) |
| `enrich.py` | مرحله enrich: تلفظ، مثال حس-خود، فیلدهای لینک CEFR، شناسه کارت. خانه آینده مترادف/متضاد (پلن کیفیت) |
| `prompts.py` | همه متن‌های prompt یکجا (داور، inflection، افزوده topic) |
| `progress.py` | فایل‌های stage، resume، rekey، backfillها |
| `accounting.py` | حسابرسی نمونه‌ها + قانون «هیچ کلیدی بی‌صدا گم نمی‌شود» |
| خودکفایی | این بسته مثل یک ابزار کارخانه است: فقط stdlib پایتون + ماژول‌های خودش. زیرساخت کوچکی که لازم دارد (key ring، استخراج JSON، ثبت telemetry، نام stageها) داخل خودش vendored می‌شود با سربرگ provenance. از factory/archive و factory/pipeline و دامنه factory/lexicon هیچ importای نیست |
